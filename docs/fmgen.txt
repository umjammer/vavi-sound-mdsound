[Overview]

  This is an implementation of an FM/PSG sound source written in C++.

  It also implements interfaces equivalent to AY8910, YM2203, YM2151, YM2608, and YM2610.

[Caution]

  This version has been slightly modified from the previous version.
  I don't think I've changed the interface, but there may be some hidden bugs.

  I haven't even checked the operation of the YM2610.

  Linear interpolation mode has been discontinued.
  The argument specifications for Init() have not changed,
  but the operation will not change even if you set interpolation = true.

  The specifications for the chip clock value given by OPNA::Init/SetRate
  are different from the version installed in previous M88s.
